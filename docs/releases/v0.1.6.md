# HSF ERP v0.1.6 — Temporary Management Preview PIN Gate

## Summary

This patch adds a server-side six-digit PIN gate in front of the existing HSF ERP management-preview UI while preserving all existing ERP modules, routes, layouts, A2PHC screens, E4BL screens, finance screens, and role-visibility demonstration behavior.

## Added

- HSF-branded `/access` screen based on the Digital Transformation Knowledge Hub access style
- server-only `HSF_ERP_ACCESS_PIN` configuration
- optional `HSF_ERP_ACCESS_SECRET` for signed preview sessions
- secure HttpOnly preview-session cookie
- configurable session duration, default 12 hours
- safe redirect back to the originally requested ERP route
- Next.js 16 `proxy.ts` request gate
- lightweight repeated-failure throttling
- public health-check exemption
- API `401` response for protected API routes without preview access
- logout endpoint for clearing the temporary preview session
- Netlify/environment documentation

## Preserved

- all non-access ERP UI and module designs
- A2PHC expansion
- E4BL UI
- finance, HR, planning, project, reporting, and administration UI
- role-visibility preview
- current HSF green branding
- mobile responsiveness of the existing ERP

## Security boundary

The PIN gate is a temporary management-preview protection layer. It is not the production authentication or RBAC system.

Production authentication will still require Supabase Auth plus HSF-controlled organization membership, roles, permissions, project/location assignments, separation of duties, and audit history.

## Netlify variables

Required:

```text
HSF_ERP_ACCESS_PIN=<six digits>
```

Recommended:

```text
HSF_ERP_ACCESS_SECRET=<long random secret>
HSF_ERP_ACCESS_SESSION_HOURS=12
```

Do not use a `NEXT_PUBLIC_` prefix.
