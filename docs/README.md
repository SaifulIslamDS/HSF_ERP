# HSF ERP Documentation

This directory contains the canonical product, architecture, workflow, module,
decision, Codex, status, and release documentation for HSF ERP.

Start with:

1. [`CURRENT-STATUS.md`](CURRENT-STATUS.md)
2. [`DOCUMENT-STACK.md`](DOCUMENT-STACK.md)
3. [`product/HSF-ERP-PRODUCT-VISION.md`](product/HSF-ERP-PRODUCT-VISION.md)
4. [`codex/NEXT-TASK.md`](codex/NEXT-TASK.md)

## Main areas

- `product/` — product vision and unresolved product decisions
- `workflows/` — end-to-end operating workflows
- `modules/` — programme-specific operating models
- `codex/` — Codex working agreement, task template, and current task
- `decisions/` — architecture decision records
- `releases/` — release notes
- `archive/` — superseded or historical documentation

The precedence rules are defined in `DOCUMENT-STACK.md`.
