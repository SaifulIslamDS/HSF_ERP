# HSF ERP Source-of-Truth Rules

The canonical institutional Source of Truth Matrix is maintained in the HSF Knowledge Hub. The ERP mirrors and implements it; the ERP must not redefine programme status, evidence states or publication governance independently.

Within the ERP repository:

1. `AGENTS.md` controls repository working rules.
2. `docs/CURRENT-STATUS.md` controls current implementation claims.
3. `docs/governance/HSF_DIGITAL_SYSTEM_CONTRACT.json` controls mirrored institutional vocabulary.
4. `docs/codex/NEXT-TASK.md` controls the approved current implementation task.
5. Current approved product requirements control business behavior.
6. ADRs control accepted technical architecture decisions.
7. Historical release notes describe what was true at that release; they do not override current status.
8. UI screens, route existence and synthetic values do not prove operational implementation or current programme facts.

Conflicts are documented and escalated rather than resolved by guessing.
